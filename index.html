How to practice
  1. Start small. Open Practice set and pick a few groups. Each kana has its romaji underneath for reference. Use a card’s pin button to keep it above Hiragana; tap again to unpin. Your selections, pins, and answer mode are remembered.
  2. Find the sound. Type the kana’s romaji and press Check or Enter, or switch to Choose an answer. Use Reveal answer if you’re stuck, then Next kana to continue.
  3. Build a combo. First-try correct answers add one point. A wrong answer, reveal, or change to your practice set resets the count. Correcting an answer doesn’t add a point.
  4. Revisit tricky kana. Mistakes and reveals go into Review missed. Each pass shows them once; a correct first try clears a kana. Review the remaining ones or go back to practice.

Your combo and missed list reset when you reload.

✳ No timer. No pressure. Just practice.
